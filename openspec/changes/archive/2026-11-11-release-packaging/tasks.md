## Workflow follow-up

- Checkpoint commits per task group on the branch, each with the user's OK, no AI
  attribution lines.
- The user installs the trial build on their machine, holds a session in a real channel
  with a second person and a game running, then uninstalls once with and once without
  the data.
- Merge into `main` with `--no-ff --log` when the user says so; archive the change in the
  same step.
- With the user's OK: tag `v1.0.0` on `main`, run `scripts\build-release.ps1` from the tag,
  and publish the GitHub release with the three files only after the user approves it.
